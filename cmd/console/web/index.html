    История

      Проверка — одно полное рукопожатие Phantom с этого компьютера, как у плиток в приложении. Запускается только кнопкой. Если Phantom сейчас подключён, проверка других серверов пойдёт через туннель: задержка будет с добавкой, а заблокированный напрямую сервер может выглядеть живым.

      Координаты определяются по IP через внешний сервис (ipwho.is, затем ipinfo.io) один раз на каждый IP и сохраняются. Сервис узнаёт адрес сервера. Если в client.yaml задана страна (country), запрос не делается и сервер на карту не попадает.

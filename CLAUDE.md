# Phantom — правила для Claude

Проект ведётся в нескольких сессиях и с разных аккаунтов Claude. Любая сессия должна уметь продолжить с последнего места.

## В начале каждой сессии
1. Прочитать `HISTORY.md` (верхние записи — где остановились) и бэклог: доска задач дашборда `cmd/console/tasks.json` (запуск: `go run ./cmd/console`).
2. `SERVERS.md` (локальный, в .gitignore) — серверы и доступ.

## ОБЯЗАТЕЛЬНО после каждой завершённой работы
- Добавить запись **сверху** в раздел «Действия» `HISTORY.md`: дата, что сделано, что осталось/следующий шаг.
- При выпуске релиза — запись в раздел «Версии» (тег, дата, суть).
- Обновить статус задачи на доске дашборда.
- `HISTORY.md` — источник раздела «История» на дашборде: записанное там сразу видно на пульте (кнопка «Обновить»).
- Закоммитить `HISTORY.md` вместе с изменениями. Работа не считается законченной без записи.

## Релизы
Версии: `android/app/build.gradle.kts`, `desktop/version.go`, `desktop/wails.json` — только X.Y.Z, суффикс `-beta.N` только в теге. Коммит с трейлером `Co-Authored-By`, тег, CI делает черновик, APK собирается локально и прикрепляется, затем Publish.
